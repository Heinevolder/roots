---
title: Spaghetti bolognese
servings: 4
time: 40
tags: [hverdag, børnevenlig, pasta]
ingredients:
  - { item: hakket oksekød, amount: 500, unit: g }
  - { item: gule løg, amount: 1, unit: stk }
  - { item: gulerødder, amount: 2, unit: stk }
  - { item: hvidløg, amount: 2, unit: fed }
  - { item: hakkede tomater, amount: 2, unit: dåse }
  - { item: tomatpuré, amount: 2, unit: spsk }
  - { item: spaghetti, amount: 400, unit: g }
  - { item: parmesan, amount: 50, unit: g }
---

1. Brun kødet i en gryde.
2. Tilsæt hakket løg, revne gulerødder og hvidløg.
3. Hæld tomater og tomatpuré ved og lad det simre i 20 minutter.
4. Kog spaghetti og server med revet parmesan.
