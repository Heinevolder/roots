---
title: Kylling i karry med ris
servings: 4
time: 35
tags: [hverdag, kylling]
ingredients:
  - { item: kyllingebryst, amount: 600, unit: g }
  - { item: løg, amount: 1, unit: stk }
  - { item: ingefær, amount: 20, unit: g }
  - { item: karry, amount: 2, unit: spsk }
  - { item: kokosmælk, amount: 400, unit: ml }
  - { item: ris, amount: 300, unit: g }
  - { item: salt }
---

1. Skær kyllingen i mundrette stykker.
2. Svits løg, ingefær og karry i lidt olie.
3. Tilsæt kylling og brun den let, hæld kokosmælk ved og lad det simre i 15 minutter.
4. Kog risene imens og server.
