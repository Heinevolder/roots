---
title: Laks med kartofler og broccoli
servings: 4
time: 30
tags: [hverdag, fisk]
ingredients:
  - { item: laks, amount: 600, unit: g }
  - { item: kartofler, amount: 1, unit: kg }
  - { item: broccoli, amount: 1, unit: stk }
  - { item: citron, amount: 1, unit: stk }
  - { item: løg, amount: 1, unit: stk }
  - { item: creme fraiche, amount: 2, unit: dl }
---

1. Kog kartoflerne.
2. Bag laksen i ovnen ved 200 grader i 12–15 minutter med citronskiver.
3. Damp broccolien og rør creme fraiche med revet citronskal til en hurtig sauce.
